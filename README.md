# VOID PULSE (한글판)

**스웜을 뚫고 원자로를 탈환하세요. 당신만의 무기 빌드로 탈출까지 살아남는 겁니다.**

네온 SF 스타일의 탑다운 생존 슈팅 게임입니다. 각기 다른 위험이 도사리는 네 개의 전장에서 무인 전투기를 조종하고, 파편을 회수하고, 강화를 선택해 펄스 건을 스웜을 관통하는 소멸 광선으로 진화시키세요. 혼자 출격하거나, 같은 LAN에 있는 친구들과 2-4인 스쿼드를 꾸릴 수 있습니다.

브라우저에서 바로 플레이됩니다. 설치나 회원가입이 필요 없습니다. 온라인 플레이는 싱글만 지원하며, 팀 플레이는 플레이어 한 명이 로컬 서버를 실행해야 합니다.

## 이번 출격, 어떻게 플레이하나요?

- **탈출과 욕심 사이에서 선택하세요.** 최소 10분 생존과 원자로 3회 복구로 미션을 완료할 수 있습니다. 혹은 이번 빌드를 유지한 채 엔드리스 도전을 계속하세요.
- **화력을 내 플레이 스타일로 조합하세요.** 레벨업마다 3장 중 1장을 선택하고, 화염 · 뇌전 · 공허 세 계열을 조합합니다. 다섯 가지 무기는 각각 진화 형태를 가집니다. 회전 블레이드, 연쇄 번개, 추적 미사일까지, 눈앞의 스웜 처리부터 대규모 연쇄 처치까지.
- **돌기만 해서는 안 됩니다. 목표를 빼앗으세요.** 스웜 사이를 뚫고 원자로 오라에 들어가 복구 진행을 지키세요. 위험 경고를 읽고, 빠져나갈 대시 한 번을 남겨 두고, 포위됐을 때는 오버드라이브 충격파로 돌파하세요.
- **함께 레벨업, 각자의 빌드.** 스쿼드는 경험치를 공유하지만 카드 선택은 각자 합니다. 팀원이 쓰러지면 가까이 가서 복구를 도울 수 있고, 누군가 버티고 있다면 전장에 복귀할 기회가 있습니다.

## 네 개의 전장, 네 가지 압력

| 전장 | 맞서게 될 것 |
| --- | --- |
| **에너지 모항** | 엄폐물 사이를 누비며 주기적 방전을 피하세요. 첫 출격에 적합합니다. |
| **서리고리** | 고드름 탄막과 감속 한파. 더 민첩한 대시로 틈을 찾으세요. |
| **용핵** | 자폭 벌, 중장갑 적, 용암 분출. 더 강한 화력으로 돌파구를 여세요. |
| **포자림** | 분열 스웜, 거미줄, 포자 독성 구역. 퇴로를 봉쇄당하지 마세요. |

## 처음 시작하기

**에너지 모항 → 싱글 출격**을 선택하세요. 무기는 자동 발사되고 기본은 자동 조준입니다. 먼저 이동해 초록 파편을 주워 첫 강화를 선택한 다음, 안내에 따라 원자로로 향하세요.

| 조작 | 키 |
| --- | --- |
| 이동 | WASD / 방향키 |
| 대시로 적 떼 통과 | Space / Shift |
| 오버드라이브 충격파 / 소멸 프로토콜 | Q / E (충전 후 사용) |
| 자동 조준 ↔ 마우스 조준 전환 | F |
| 빌드와 진화 레시피 보기 | B |
| 메뉴 / 싱글 일시정지 | Esc / P |

터치 기기에서는 가상 조이스틱과 스킬 버튼이 제공됩니다. 설정에서 볼륨, 저사양 그래픽, 화면 흔들림·섬광 줄이기를 조정할 수 있습니다. 전체 조작법과 진화 레시피는 [파일럿 매뉴얼](docs/PLAYER_GUIDE.md)을 참고하세요.

## 친구와 함께 하기

**2-4인 LAN 협동**을 지원합니다. 방장 한 명을 정해 Python 3가 설치된 컴퓨터에 이 저장소를 내려받아 압축을 풀고, 디렉터리에서 다음을 실행하세요:

```bash
python3 scripts/server.py
```

macOS에서는 `start.command`를 더블클릭해도 되고, npm이 설치된 플레이어는 `npm start`를 써도 됩니다.

1. 모두 같은 LAN에 연결하고 브라우저에서 `http://<방장의 LAN IP>:8123`을 엽니다(방장 본인은 `http://localhost:8123`도 가능).
2. 방장은 **팀 플레이 → 방 만들기**를 선택하고 방 이름과 비밀번호를 팀원에게 알려 줍니다.
3. 팀원이 방에 참가하면 방장이 전장을 고르고 개시합니다.

팀킬은 없습니다. 멀티에서 카드를 고르는 동안에도 전투는 계속되니 팀원의 공간을 배려하세요. GitHub Pages의 온라인 플레이에는 멀티 중계가 없으므로, 팀 플레이는 방장의 로컬 주소를 이용하세요.
