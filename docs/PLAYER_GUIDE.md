# VOID PULSE · 파일럿 매뉴얼

[게임 홈으로](../README.md) · [온라인 플레이](https://sigco3111.github.io/void-pulse/) · [中文原文](PLAYER_GUIDE.zh.md)

빌드를 더 깊이 파고들고 싶은 파일럿을 위한 상세 조작법, 빌드 레시피, 전장 규칙입니다.

## 조작

| 키 | 기능 |
| --- | --- |
| WASD / 방향키 | 이동 |
| F / 마우스 | 자동 조준 ↔ 마우스 조준 전환(기본 자동, 발사는 항상 자동) |
| SPACE / SHIFT | 대시(무적 프레임, 적 통과 가능) |
| Q / 마우스 우클릭 | 오버드라이브 충격파(에너지가 가득 차면 전장 정리) |
| E | 소멸 프로토콜(파편으로 충전하는 궁극기) |
| ESC / P | 메뉴 열기: 싱글은 일시정지, 멀티는 설정/방 나가기 가능하지만 월드는 계속 진행 |
| B | 빌드, 전체 진화 레시피, 다음 단계 수치 보기 |
| M | 음소거 |
| R | 카드 선택 시 리롤(판당 2회), 결과 화면에서 빠른 재시작 |
| 오른쪽 아래 설정 | 음악 / 효과음 볼륨, 자동 조준, 화면 흔들림·섬광 줄이기, 그래픽 |

터치 기기에서는 가상 조이스틱, 자동 조준, 대시 / Q / E 스킬 버튼이 자동으로 켜집니다.

## 전장과 빌드

- **4개 행성 출격**: 메인 메뉴에서 행성을 고릅니다. 멀티에서는 방장이 로비에서 선택하고, 결과 후 로비로 돌아가 행성을 바꿀 수 있습니다. 새 판은 빌드를 초기화합니다. 클라이언트는 지형, 환경 이벤트, 수치를 자동 동기화하며, 전투 도중 규칙이 바뀌지 않습니다.
  - 에너지 모항: 균형 잡힌 혼합 스웜, 단발 슈터, 주기적 방전.
  - 서리고리: 이동 속도 +12%, 대시 쿨다운 −20%. 질주자와 헌터 위주, 고드름 슈터의 3방향 탄막, 한파의 강한 감속.
  - 용핵: 무기 피해 +18%, 최대 체력 +10. 자폭 벌과 탱크 위주, 슈터는 중형 이중탄 발사, 자폭 벌은 폭발 시 원형 파편을 뿌립니다(처치로 발동한 아군 연쇄는 적탄을 만들지 않음).
  - 포자림: 초당 0.6 HP 회복, 획득 범위 +25%. 분열체와 그물술사 위주, 슈터와 보스가 포자 구역을 깔고, 구역 안에서는 감속과 지속 피해.
- **전투 커서**: 데스크톱 전투 화면에서는 고대비 조준 커서를 사용하고, 메뉴·일시정지·설정에서는 일반 마우스로 돌아옵니다. 터치는 기존 조이스틱 조작을 유지합니다.
- 목표 구역 밖에서 시작합니다. 앞으로 이동해 첫 초록 파편을 줍고 첫 카드 선택을 경험한 뒤 원자로로 향하세요.
- 처치 시 **에너지 파편**이 떨어지고, 주우면 레벨업합니다. 레벨마다 3장의 강화 카드 중 1장을 고릅니다. LV20 이후에는 필요 경험치가 선형으로 늘어나 긴 판의 레벨업 비용이 이차적으로 폭증하지 않습니다.
- **원자로 쟁탈**: 24초 후 처음 온라인, 이후 85초마다 38초의 확보 창이 열립니다. 중앙 황금 오라에 들어가 누적 7초를 버티세요. 다인 협력은 최대 50%까지 가속하고, 오라 안에 적이 있으면 충전이 30%로 떨어지며, 벗어나면 천천히 후퇴합니다. 완료 시 생존 팀원 전원 18 HP 회복, 팀 전체 오버드라이브 에너지 25, 18초간 연사 속도 +25%, 팀 점수 +400.
- **전술 미니맵**: 팀원, 적, 엄폐물, 보급, 중앙 목표, 방전 구역을 표시합니다. 목표 패널은 거리, 카운트다운, 충전 진행, 스웜 단계를 보여 줍니다.
- **업그레이드 리롤**: 판당 2회. 직전 카드 조합을 우선 회피하지만 진화 카드가 보장되는 규칙은 유지됩니다. 멀티의 카드 선택은 작은 패널로 표시되고 월드는 계속 돌아가며, 선택 후 0.8초의 보호를 받습니다.
- **계열 시너지(핵심 콤보)**: 모든 카드는 화염 🔥 / 뇌전 ⚡ / 공허 🌑 세 계열 중 하나에 속합니다.
  같은 계열에 투자한 레벨이 높을수록 그 계열 카드가 뜰 확률이 올라가고, 4 / 8 / 13레벨 투자 시 각성 능력이 열립니다:
  - 🔥 화염: **잔불**(피해 +12%) → **폭염**(처치 시 폭발) → **염천**(무기와 계열 피해에 점화 부여, Q/E 제외)
  - ⚡ 뇌전: **신속**(연사 속도 +12%) → **낙뢰**(처치 시 25% 확률로 하늘에서 벼락) → **뇌신**(5초마다 가장 밀집한 적군 폭격)
  - 🌑 공허: **강인**(체력 +20, 장갑 +1) → **역습**(피격 시 노바 발산) → **포식**(8초마다 주변의 체력 낮은 적 처형)
- **무기 진화**: 무기 만렙 5 + 대응 패시브 → 금색 진화 카드가 반드시 등장:
  - 펄스 건 + 오버클럭 모듈 → **소멸 광선**(무한 관통의 중형 광선)
  - 오르빗 블레이드 + 이온 추진기 → **폭풍 검역**(8개 블레이드 회전 + 전방향 블레이드 스톰)
  - 추적 미사일 + 증폭 코어 → **스웜 하이브**(모자 미사일 8발)
  - 테슬라 아크 + 약점 스캐너 → **천벌 뇌옥**(12연쇄 번개 + 지속 뇌옥 구역)
  - 노바 버스트 + 나노 장갑층 → **초신성 붕괴**(중력 견인 + 폭발 + 실드)
- **연쇄 처치**: 연쇄 점수 배율은 최대 3배, 연쇄 15회마다 금색 충격파가 터집니다.
- **오버드라이브 [Q]**: 근접 돌파, 탄막 소거, 짧은 무적. 피해는 85 + 대상 최대 체력의 8%.
- **소멸 프로토콜 [E]**: 전장의 탄막을 지우고, 일반 적에게 500 피해, 보스에게는 최대 체력의 25% 피해. 파편을 주워 충전하며, 쓸수록 충전이 느려집니다.
- Q/E는 점화를 부여하지 않고 추가 처치 폭발, 낙뢰, 연쇄 충격 피해도 발동시키지 않습니다. 일반 스킬 처치는 25%만 에너지로 돌려주고 발당 최대 25 Q까지 반환됩니다. 보스는 추가 보상입니다: 생존 팀원 전원 100 Q / 40 E.
- 적은 시간이 지나며 순차 해금됩니다: 질주자 25초, 분열체 55초, 슈터 78초, 자폭 벌 96초, 탱크 125초, 헌터 148초, 그물술사 175초. 150초 후부터 엘리트 변형이 점차 추가됩니다.
- **위협 예산**: 36초 주기로 진행 / 절정 / 숨 돌리기가 반복됩니다. 중형과 원거리 적은 더 많은 예산을 소모합니다. 경고 구역이 가득 차면 스폰이 미뤄지고, 플레이어가 구역에 들어가면 해당 스폰이 취소됩니다.
- **빙빙 돌기 방지**: 소수의 적이 전방을 차단합니다. 첫 포위는 72초, 이후 84초마다 한 번씩 발생합니다.
- **보이드 오버로드**는 180초에 처음 등장하고 이후 165초마다 한 마리씩 나옵니다(MK.II부터 나선 탄막 추가). 돌진 전 방향을 고정하고 0.75초 모으기를 합니다. 보급 포드는 주기적으로 투하됩니다.
- 결과 화면에는 마지막 피해 원인, 최종 빌드, 본인의 실제 피해 기여도가 표시됩니다. 최고 기록은 행성, 싱글/시작 인원, 미션/엔드리스별로 나눠 저장됩니다(localStorage). 클라이언트는 각자의 기기에서 신기록을 따로 계산합니다. 구버전의 혼합 기록은 원래 저장 키에 남으며 새 분류에 섞이지 않습니다.
